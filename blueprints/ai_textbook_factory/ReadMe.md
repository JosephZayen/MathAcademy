#生成教材阶段

##询问AI
1.先问o3中国高校高频考点 [按 A（必考）/B（常考）/C（偶考）分级]
2.询问AI这本教材哪里会考察定量公式，只有那里才需要公式，其它地方尽量提示AI避免使用公式



##处理目录
3.标记和划分目录

3.1然后针对考点，对目录进行\n或者合并，对于高频考点，
使用提示词拼接，用更详细的提示词，并且拆分得细一些

3.2对目录进行LABEL_A,LABEL_B,LABEL_C,LABEL_S的标记。
LABEL_S表示会考察公式
除了常考及含定量公式的内容，提示AI避免使用公式


4.生成教材
//注：对于高频考点，可以把试卷和目录发给AI，让它帮你归纳A/B/C

5.做试卷
